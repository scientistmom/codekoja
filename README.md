# CodeKoja

A free browser game that helps children learn coding through block puzzles and Python lessons. Available in English and Hungarian, with a learning map and looks unlocked using coins earned in the game.

## Credits

- [Monaco Editor 0.57.0](https://github.com/microsoft/monaco-editor/tree/v0.57.0) provides the code editor.
- [Pyodide 314.0.6](https://github.com/pyodide/pyodide/tree/314.0.6) runs Python in the browser.

Both load from jsDelivr; an internet connection is required. Their authors retain their respective rights.

## Game data

The game does not collect or upload your code, answers or progress. Saves and preferences stay in your browser and can be removed using Reset everything or by clearing this site's browser data. CDN downloads involve ordinary connection information, such as your IP address.
